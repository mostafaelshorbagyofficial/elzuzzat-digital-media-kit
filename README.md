# ProMedia × ElZuzzat — Official Digital Media Kit & Presentation

An interactive, high-performance commercial presentation and digital media kit representing **ElZuzzat**, exclusively managed and presented by **ProMedia**.

Built with React 18, TypeScript, Tailwind CSS, and Vite.

## Features

- **Executive Agency Introduction:** Official ProMedia presenting slide with brand credentials.
- **Creator Showcase:** Authentic visual assets featuring ElZuzzat with comprehensive audience velocity data (200M+ Quarterly Views).
- **Interactive Portfolio Galleries:** Curated campaigns across **Retail**, **Tourism**, and **Restaurants** with authentic Instagram Reel thumbnails and embedded playback modal.
- **Sponsorship Opportunities:** Brand integration tiers and content formats.
- **Official Commercial Packages:**
  - Full Social Media Package (Facebook + Instagram + TikTok) — EGP 300,000
  - Two-Platform Package (Instagram + TikTok) — EGP 250,000
  - Dedicated Instagram Package — EGP 200,000
  - Direct WhatsApp booking integration with pre-filled package identification.
- **Bilingual Experience:** Seamless English (LTR) and Arabic (RTL) support.
- **Enterprise-Grade UI/UX:** Editorial typography, pure white aesthetic, fast load times, and fully responsive across mobile, tablet, and desktop.

## Tech Stack

- **Framework:** React 18
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React + Custom Brand SVGs
- **Build Tool:** Vite

## Getting Started

### Prerequisites

- Node.js 18+
- npm or pnpm

### Installation

```bash
git clone https://github.com/mostafaelshorbagyofficial/elzuzzat-digital-media-kit.git
cd elzuzzat-digital-media-kit
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
